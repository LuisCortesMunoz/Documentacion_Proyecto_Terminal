# Documentacion_Proyecto_Terminal

Sitio de documentación técnica de **LAVO — Logic Automation, Validation & Operation**
(Proyecto Terminal · Ingeniería Mecatrónica).

## Estructura

```
index.html            Página de documentación
documentacion.html    Ruta heredada: redirige a index.html conservando el ancla (#arquitectura…)
assets/css/docs.css   Estilos (tokens de color en :root)
assets/js/docs.js     Navegación, scrollspy, drawer móvil, copiar código, lightbox
assets/img/           Logotipos
assets/resultados/    Capturas de las pruebas
.nojekyll             Sirve los archivos tal cual en GitHub Pages
```

Los videos de Resultados se cargan desde el sitio del proyecto principal
(`Proyecto_Final_Prospectiva_Tecnologia/assets/resultados/`) para no duplicar ~250 MB.

## Ver en local

Abre `index.html` en el navegador (los videos requieren conexión a internet).

## Publicar

En GitHub: *Settings → Pages → Deploy from a branch → `main` / root*.
